 Instagram MERN Clone

A full-stack Instagram clone built using the MERN stack (MongoDB, Express, React, Node.js).

 Features
- User Authentication (JWT)
- Create, Like, Comment on Posts
- Follow / Unfollow Users
- Reels Feature
- Notifications System
- Real-time Chat (Socket.io)
- Profile Management

  Tech Stack
- Frontend: React, Redux, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT

 Installation

 Backend
cd backend  
npm install  
npm run dev  

 Frontend
cd frontend  
npm install  
npm start
